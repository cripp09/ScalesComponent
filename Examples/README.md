# 📚 Примеры использования ScalesComponent

В этой директории собраны готовые примеры интеграции библиотеки ScalesComponent с различными платформами.

## 📋 Содержание

- **[1C/](1C/)** — Готовая обработка для 1С:Предприятие 8.3
  - `ScalesConnector.epf` — файл обработки
  - `README.md` — инструкция по установке и использованию
  
- **[CSharp/ConsoleApp/](CSharp/ConsoleApp/)** — Консольное приложение на C# (.NET Framework 4.7.2+)
  - `Program.cs` — исходный код
  - `ScalesComponent.Examples.ConsoleApp.csproj` — файл проекта
  - `README.md` — инструкция по сборке и запуску

- **[Python/](Python/)** — Пример использования через pywin32
  - `example.py` — скрипт примера
  - `requirements.txt` — зависимости
  - `README.md` — инструкция по установке и запуску

## 🚀 Быстрый старт

### 1. Регистрация библиотеки

Перед использованием примеров зарегистрируйте `ScalesComponent.dll`:

```cmd
C:\Windows\Microsoft.NET\Framework\v4.0.30319\regasm.exe "путь\к\ScalesComponent.dll" /codebase
```

(Для 64-битной 1С используйте путь `Framework64`)

### 2. Выбор примера

- **1С:Предприятие** — если вы интегрируете весы в учётную систему
- **C# ConsoleApp** — если вы разрабатываете собственное приложение на .NET
- **Python** — если вы используете Python для автоматизации или анализа данных

## ⚠️ Важное примечание

Примеры демонстрируют работу с **3 протестированными брендами весов**:
- ✅ CAS CI-200A
- ✅ Massa-K ТВ-М
- ✅ Metrisoft

Для остальных брендов (реализованных по документации) может потребоваться дополнительная настройка. См. [TESTING_STATUS.md](../TESTING_STATUS.md) для подробностей.
