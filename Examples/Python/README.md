# 🐍 Пример использования на Python

Пример интеграции библиотеки ScalesComponent с Python через COM-интерфейс (pywin32).

## 📋 Требования

- **ОС:** Windows 7/8/10/11
- **Python:** 3.7 или выше
- **Библиотеки:** pywin32

## 🚀 Установка

1. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```

2. Зарегистрируйте библиотеку `ScalesComponent.dll` (от администратора):
   ```cmd
   C:\Windows\Microsoft.NET\Framework\v4.0.30319\regasm.exe "путь\к\ScalesComponent.dll" /codebase
   ```

## 💻 Запуск

```cmd
python example.py
```

## ⚙️ Настройка

Откройте файл `example.py` и измените параметры подключения:

```python
port_name = "COM3"      # Ваш COM-порт
baud_rate = 9600        # Скорость передачи данных
scales_type = "Auto"    # Тип весов (или конкретный бренд)
```

## 🎮 Возможности

- ✅ Получение стабильного веса с таймаутом
- ✅ Мгновенное чтение текущего веса
- ✅ Тарирование весов
- ✅ Проверка статуса подключения
- ✅ Проверка стабильности веса
- ✅ Непрерывный мониторинг в реальном времени

## 📚 Интеграция в ваш проект

Минимальный пример использования:

```python
import win32com.client

# Создаём COM-объект
scales = win32com.client.Dispatch("ScalesComponent.Scales.1")

# Подключаемся к весам
scales.Connect("COM3", 9600, "Auto")

# Получаем стабильный вес
weight = scales.GetStableWeight(5000)
print(f"Вес: {weight} кг")

# Отключаемся
scales.Disconnect()
```

## 🐛 Обработка ошибок

Если возникла ошибка `COMError`, проверьте:
1. Библиотека `ScalesComponent.dll` зарегистрирована через `regasm`
2. Вы используете 64-битную Python с 64-битной DLL (или 32/32)
3. COM-порт доступен и не занят другим приложением

## ⚠️ Ограничения

- Работает только на Windows (из-за COM-интерфейса)
- Требуется регистрация DLL в системе
- Для Linux/macOS используйте нативные библиотеки работы с последовательным портом
