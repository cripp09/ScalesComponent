# Коммерческое использование ScalesComponent

## Бесплатная версия (MIT License)

Базовая библиотека доступна бесплатно:

- ✅ **3 бренда с гарантией работы** (CAS CI-200A, Massa-K ТВ-М, Metrisoft) — физически протестированы автором
- ⚠️ **12 брендов по документации** — работают согласно официальным протоколам, но требуют верификации на вашем оборудовании
- Базовый API для работы с COM-портом
- Документация и примеры кода
- Сообщество (Issues, Discussions)

Для компаний и интеграторов предлагаем расширенную версию:

1. **Готовые модули для 1С**

   - Встроенное логирование и обработка ошибок
   - Автоматическое определение весов

2. **Расширенная поддержка брендов**
   - ✅ **3 бренда с гарантией работы** (CAS CI-200A, Massa-K ТВ-М, Metrisoft) — физически протестированы автором
