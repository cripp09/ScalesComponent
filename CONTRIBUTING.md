# Как внести вклад в ScalesComponent

Мы приветствуем любые улучшения проекта! Вот как вы можете помочь:

## 🐛 Сообщить об ошибке

1. Проверьте, что ошибка еще не зафиксирована в [Issues](https://github.com/cripp09/ScalesComponent/issues)
2. Создайте новый Issue с описанием:
   - Модель весов
   - Что ожидалось
   - Что произошло
   - Пример данных с весов (если возможно)

## 💡 Предложить новую функцию

1. Создайте Issue с меткой "enhancement"
2. Опишите, зачем нужна эта функция
3. Мы обсудим и, если подходит, добавим в roadmap

## ⚖️ Добавить поддержку новых весов

### Если у вас есть физический доступ к весам:

1. Форкните репозиторий
2. Создайте класс `YourBrandParser.cs` в папке `Parsers/`
3. Реализуйте интерфейс `IScalesParser`
4. Добавьте тесты (папка `Tests/`)
5. **Обновите README.md** — добавьте бренд в таблицу **"✅ Протестировано на реальном оборудовании"**
6. Отправьте Pull Request

### Если вы пишете парсер по документации:

1. Форкните репозиторий
2. Создайте класс `YourBrandParser.cs` в папке `Parsers/`
3. Реализуйте интерфейс `IScalesParser`
4. Добавьте пометку в комментариях кода: `/// ⚠️ Реализовано по документации, требует верификации`
5. **Обновите README.md** — добавьте бренд в таблицу **"⚠️ Реализовано по документации"**
6. Отправьте Pull Request

### Пример парсера:

```csharp
public class YourBrandParser : IScalesParser
{
    public ScalesReading Parse(string line)
    {
        // Ваш код парсинга
    }
    
    public string GetDetectionPattern() => "ваш паттерн";
    public string GetBrandName() => "YourBrand";
}
```

## 📝 Улучшить документацию

- Исправление опечаток
- Добавление примеров
- Перевод на другие языки

Всё это приветствуется! Отправляйте Pull Request.

## 🤝 Стать контрибьютором

Если вы активно участвуете в проекте, мы можем добавить вас в команду с правами на запись в репозиторий.
