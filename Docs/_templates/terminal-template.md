# CAS CI-200A

**Производитель:** CAS (Южная Корея)  
**Тип:** Индикатор весовой (для платформенных/напольных весов)  
**Интерфейс:** RS-232C (DB9 Male)  
**Статус:** ✅ Протестировано и работает

---

## 📋 Быстрый старт

Если нужно быстро подключить весы к библиотеке ScalesComponent:

1. **Настрой весы** (меню → F28=4, F29=1, F31=1 или 2)
2. **Подключи нуль-модемный кабель** (TX↔RX, RXTX, GND↔GND)
3. **В 1С/Python:**
   ```python
   scales.Connect("COM3", 9600, "CAS")
   weight = scales.GetStableWeight(5000)
   ```

## 1. Включение режима передачи данных

### Пошаговая инструкция через меню

#### Вход в режим настроек

**Если весы выключены:**
1. Нажми и **удерживай** клавишу **`2`**
2. Не отпуская `2`, нажми **`Power`** (включение питания)
3. На дисплее появится `<F    01>`

**Если весы уже включены:**
1. Нажми и **удерживай** клавишу **`2`** в течение **3 секунд**
2. На дисплее появится `<F    01>`

#### Настройка параметров COM-порта

После входа в меню:

| Шаг | Действие | Значение |
|-----|----------|----------|
| 1 | Введи **`28`** → нажми **`SET`** | Выбор функции скорости |
| 2 | Введи **`4`** → нажми **`SET`** | **9600 бит/сек** (стандарт библиотеки) |
| 3 | Введи **`29`** → нажми **`SET`** | Выбор функции режима передачи |
| 4 | Введи **`1`** → нажми **`SET`** | **Подключение к ПК/дисплею** |
| 5 | Введи **`31`** → нажми **`SET`** | Выбор функции условий передачи |
| 6 | Введи **`1`** или **`2`** → нажми **`SET`** | См. таблицу ниже |
| 7 | **Удерживай `SET` 3 секунды** | Выход из меню с сохранением |

#### Выбор режима передачи (F31)

| Значение | Описание | Когда использовать |
|----------|----------|-------------------|
| **F31 = 1** | **Постоянная передача** (независимо от стабильности) | ✅ **Рекомендуется** для ScalesComponent. Весы шлют данные непрерывно, библиотека сама фильтрует стабильные значения. |
| **F31 = 2** | Передача только при стабилизации | ⚠️ Можно использовать, но весы будут молчать, пока вес нестабилен. |
| **F31 = 3** | Передача по запросу (командой) | ❌ Не рекомендуется. Требует отправки команд. |
| **F31 = 4** | Командный режим | ❌ Не для этой библиотеки. |

> **Рекомендация:** Используй **F31 = 1** (постоянная передача). Библиотека ScalesComponent сама определит стабильные показания через флаг `ST`/`US`.

#### Полная таблица функций

##### F28 — Скорость обмена данными
| Значение | Скорость |
|----------|----------|
| F28 = 0 | 600 бод |
| F28 = 1 | 1200 бод |
| F28 = 2 | 2400 бод |
| F28 = 3 | 4800 бод |
| **F28 = 4** | **9600 бод** ✅ (рекомендуется) |
| F28 = 5 | 19200 бод |
| F28 = 6 | 38400 бод |
| F28 = 7 | 57600 бод |
| F28 = 8 | 115200 бод |

##### F29 — Назначение COM1
| Значение | Описание |
|----------|----------|
| F29 = 0 | Подключение к принтеру |
| **F29 = 1** | **Подключение к ПК или доп. дисплею** ✅ |

##### F31 — Условия передачи
| Значение | Описание |
|----------|----------|
| F31 = 0 | Передача отключена |
| **F31 = 1** | **Непрерывная передача** ✅ |
| F31 = 2 | Только при стабилизации |
| F31 = 3 | По запросу (командой) |
| F31 = 4 | Командный режим |

## 2. Распиновка COM-порта (RS-232)

### Схема подключения

```
        CAS CI-200A (DB9 Male "папа")
         ╔═══╤═══╤═══╤═══╤═══╗
         ║ 1 │ 2 │ 3 │ 4 │ 5 ║
         ╠═══╪═══╪═══╪═══╪═══╣
         ║   │RXD│TXD│   │   ║
         ╚═══╧═══╧═══╧═══╧═══╝
         ╔═══╤═══╤═══╤═══╤═══╗
         ║ 6 │ 7 │ 8 │ 9 │   ║
         ╠═══╪═══╪═══╪═══╪═══╣
         ║   │GND│   │   |   ║
         ╚═══╧═══╧═══╧═══╧═══╝

        Компьютер (DB9 Female "мама")
         ╔═══╤═══╤═══╤═══╤═══╗
         ║ 1 │ 2 │ 3 │ 4 │ 5 ║
         ╠═══╪═══╪═══╪═══╪═══╣
         ║   │TXD│RXD│   │GND║
         ╚═══╧═══╧═══╧═══╧═══╝
         ╔═══╤═══╤═══╤═══╤═══╗
         ║ 6 │ 7 │ 8 │ 9 │   ║
         ╚═══╧═══╧═══╧═══╧═══╝
```

### Таблица соединений

| Контакт (CAS CI-200A) | Сигнал | Подключение к ПК | Направление |
|:---------------------:|--------|:----------------:|:-----------:|
| **2** | RXD (Receive Data) | **3** (TXD) | ← Принимает от ПК |
| **3** | TXD (Transmit Data) | **2** (RXD) | → Передаёт на ПК |
| **7** | GND (Ground) | **5** (GND) |  Земля |

> ⚠️ **ВАЖНО:** Нужен **нуль-модемный кабель** (null-modem, cross-over)!  
> Обычный прямой кабель **НЕ РАБОТАЕТ**.  
> 
> **Схема:** TX↔RX, RX↔TX, GND↔GND

### Минимальный кабель (3 провода)

Для работы с библиотекой ScalesComponent достаточно **трёх проводов**:

```
CAS CI-200A (DB9 Male)      ПК (DB9 Female или USB-COM)
     пин 2 (RXD)  ────────────►  пин 3 (TXD)
     пин 3 (TXD)  ◄────────────  пин 2 (RXD)
     пин 7 (GND)  ─────────────  пин 5 (GND)
```

### Если используешь USB-to-RS232 адаптер

1. Подключи адаптер к USB
2. Открой **Диспетчер устройств** → **Порты (COM и LPT)**
3. Найди свой адаптер (например, "Prolific USB-to-Serial")
4. Запомни номер COM-порта (COM3, COM4 и т.д.)
5. Подключай по схеме выше

## 3. Подключение тензодатчика

### Разъём: DB9 (Female "мама")

Индикатор CAS CI-200A использует **круглые разъемы (типа GX16 или DIN)** для подключения тензодатчика (или весовой платформы с тензодатчиками).

### Распиновка (ориентируйся на цифры на корпусе разъёма!)

```
        GX16 или DIN (вид со стороны терминала)
         ╔═══╤═══╤═══╤═══╤═══╗
         ║ 1 │ 2 │ 3 │ 4 │ 5 ║
         ╠═══╪═══╪═══╪═══╪═══║
         ║EXC│EXC│SIG│SIG│SCR║
         ║ + │ - │ + │ - │   ║
         ╚═══╧═══╧═══╧═══╧═══╝
         ╔═══════╤═══╤═══╤═══╗
         ║ 6 │ 7 │   │   │   ║
         ╠═══╪═══╪═══╪═══╪═══╣
         ║SEN│SEN│   │   │   ║
         ║ + │ - │   │   │   ║
         ╚═══╧═══╧═══╧═══╧═══╝
```

### Таблица контактов

| Пин | Сигнал | Описание | 4-проводная схема |
|:---:|--------|----------|:-----------------:|
| **1** | **EXC+** | Питание тензодатчика (+) | ← Сюда же перемычка с **6** |
| **2** | **EXC-** | Питание тензодатчика (-) | ← Сюда же перемычка с **7** |
| **3** | **SIG+** | Сигнальный (+) | — |
| **4** | **SIG-** | Сигнальный (-) | — |
| **5** | **SCR** | Экран кабеля (Shield) | Подключить к земле |
| **6** | **SEN+** | Обратная связь (+) | ⬅️ Перемычка на **1** |
| **7** | **SEN-** | Обратная связь (-) | ⬅️ Перемычка на **2** |
| 8 | NC | Не используется | — |
| 9 | NC | Не используется | — |

> **Важно для 4-проводных тензодатчиков:**  
> Если у тебя **4-проводной** тензодатчик (без SEN+ и SEN-), сделай **перемычки**:
> - **Пин 1 ↔ Пин 6** (EXC+ соединить с SEN+)
> - **Пин 2 ↔ Пин 7** (EXC- соединить с SEN-)

### Цветовая маркировка проводов тензодатчика

Стандартная расцветка (может отличаться у разных производителей!):

| Цвет провода | Сигнал | Пин на CAS CI-200A |
|--------------|--------|:------------------:|
| 🔴 **Красный** | EXC+ (Excitation +) | **1** |
| ⚫ **Чёрный** | EXC- (Excitation -) | **2** |
| 🟢 **Зелёный** | SIG+ (Signal +) | **3** |
| ⚪ **Белый** | SIG- (Signal -) | **4** |
| 🛡️ **Экран** | Shield (GND) | **5** |

> ⚠️ **Проверяй маркировку на своём тензодатчике!**  
> Некоторые производители используют другую расцветку. Всегда сверяйся с документацией к тензодатчику.

## 4. Протокол обмена данными

### Формат передаваемых данных

Весы CAS CI-200A в режиме **F29=1** (подключение к ПК) и **F31=1** (непрерывная передача) шлют строки следующего формата:

```
STATUS,TYPE,UNIT,   WEIGHT kg\r\n
```

### Реальные примеры из лога

```
US,NT,▒,   244.5 kg
ST,GS,▒,   152.0 kg
OL,NT,▒,  1504.5 kg
```

### Расшифровка полей

| Поле | Значения | Описание |
|------|----------|----------|
| **1. STATUS** | `ST` — Stable (стабильный)<br>`US` — Unstable (нестабильный)<br>`OL` — **Overload** (перегруз!) | Показывает стабильность взвешивания |
| **2. TYPE** | `GS` — Gross (брутто)<br>`NT` — Net (нетто)<br>`TA` — Tare (тара) | Тип взвешивания |
| **3. UNIT** | `▒` — символ кодировки (кг/г/фунт)<br>*(часто отображается как кракозябра)* | Единица измерения (игнорируется) |
| **4. WEIGHT** | Число с плавающей точкой<br>Пример: `   244.5` (с выравниванием) | Значение веса в кг |

### ️ Важные замечания

1. **`OL` (Overload) — ПЕРЕГРУЗ!**  
   Если первое поле = `OL`, значит весы перегружены. Значение веса **НЕВАЛИДНО**, его нельзя использовать!
   
   ```
   OL,NT,,  1504.5 kg  ← Это НЕ реальный вес! Сними груз!
   ```

2. **Символ `▒`** — это артефакт кодировки дисплея весов. Парсер библиотеки автоматически его удаляет.

3. **Пробелы перед числом** — весы выравнивают вывод по правому краю. Не обращай внимания, парсер всё корректно обработает.

4. **Стабильный вес** — ищи строки с `ST` в первом поле:
   ```
   ST,GS,,   152.0 kg  ← Можно записывать!
   ```

### Как библиотека обрабатывает данные

Библиотека **ScalesComponent** автоматически:
- ✅ Фильтрует символы-артефакты (`▒`)
- ✅ Игнорирует перегруз (`OL` → возвращает `Weight = 0`)
- ✅ Определяет стабильность (`ST` → `IsStable = true`)
- ✅ Парсит вес с учётом пробелов и единиц измерения

## 5. Использование с библиотекой ScalesComponent

### Пример на Python

```python
import win32com.client
import pythoncom

pythoncom.CoInitialize()
scales = win32com.client.Dispatch("ScalesComponent.Scales.1")

# Подключение (Auto = автоопределение типа)
if scales.Connect("COM3", 9600, "Auto"):
    print("✅ Весы подключены")
    
    # Получение стабильного веса (ждёт до 5 сек)
    weight = scales.GetStableWeight(5000)
    
    if weight > 0:
        print(f"✅ Стабильный вес: {weight} кг")
    else:
        print(f"❌ Ошибка: {scales.GetLastError()}")
    
    # Тарирование
    scales.Tare()
    
    # Отключение
    scales.Disconnect()
else:
    print(f"❌ Ошибка подключения: {scales.GetLastError()}")

pythoncom.CoUninitialize()
```

## 6. Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| **Нет данных в терминале** | Прямой кабель вместо нуль-модемного | Используй **null-modem** кабель (TX↔RX, RX↔TX) |
| **Кракозябры (`▒▒`)** | Неправильный Baud Rate | Установи **F28 = 4** (9600 бод) |
| **Вес всегда 0** | Режим F31 = 0 (передача отключена) | Установи **F31 = 1** (непрерывная передача) |
| **Вес всегда OL** | Перегруз платформы / неверная калибровка | Сними груз, проверь калибровку |
| **Данные идут, но парсер не видит** | Неправильный тип весов в коде | Используй `"CAS"` или `"Auto"` в `Connect()` |
| **Скачущие показания** | Вибрация / сквозняк / неровная поверхность | Поставь весы на устойчивую поверхность |
| **COM-порт не открывается** | Порт занят другой программой | Закрой Putty, терминал, другую 1С |
| **Ошибка 0x800401F3** | DLL не зарегистрирована | Запусти `regasm` от администратора |

## 7. Диагностика

### Как проверить, что весы шлют данные

1. **Через Putty (или любой терминал):**
   - Открой Putty
   - Выбери **Serial**
   - Укажи COM-порт (например, COM3)
   - Speed: **9600**
   - Data bits: **8**, Stop bits: **1**, Parity: **None**
   - Нажми **Open**
   - Положи груз на весы
   - Должны появиться строки: `US,NT,▒,   152.0 kg`

2. **Через Python:**
   ```python
   import serial
   ser = serial.Serial('COM3', 9600, timeout=1)
   while True:
       if ser.in_waiting > 0:
           print(ser.readline().decode('utf-8', errors='ignore'))
   ```

3. **Через Диспетчер устройств Windows:**
   - Открой **Диспетчер устройств** → **Порты (COM и LPT)**
   - Убедись, что COM-порт отображается без восклицательных знаков
   - Если есть жёлтый треугольник — переустанови драйвер USB-COM адаптера
