# Масса-К (Massa-K)

**Производитель:** Масса-К (Россия, Санкт-Петербург)  
**Тип:** Весовые терминалы (серии А, МК, ТВ, МА)  
**Интерфейс:** RS-232 (DB9)  
**Протокол:** Протокол №2 (бинарный, запрос-ответ)  
**Статус:** ✅ Протестировано и работает

## 📋 Быстрый старт

Если нужно быстро подключить весы Масса-К к библиотеке ScalesComponent:

1. **Настрой весы** (меню → Протокол №2, скорость 4800)
2. **Подключи кабель** (обычный прямой, не нуль-модемный!)
3. **В 1С/Python:**
   ```python
   scales.Connect("COM1", 4800, "MassaK")
   weight = scales.GetStableWeight(5000)
   ```

## 1. Включение режима передачи данных

### Пошаговая инструкция через меню

#### Вход в режим настроек

**Для терминалов серии А (ТВ-А, Т-А, МК-А):**
1. Зажмите кнопку **F** (или **Меню**) при включении весов
2. На дисплее появится меню настроек
3. Найдите раздел **Интерфейс RS-232** или **COM-порт**

**Для терминалов серии МА:**
1. Нажмите и удерживайте **МЕНЮ** 3 секунды
2. Введите пароль (по умолчанию: `1111` или `0000`)
3. Перейдите в раздел **Связь** → **RS-232**

#### Настройка параметров COM-порта

Установите следующие параметры:

| Параметр | Значение | Описание |
|----------|----------|----------|
| **Протокол** | **Пр.2** (Протокол №2) | Бинарный протокол запрос-ответ |
| **Скорость** | **4800** бод | Стандартная скорость для Пр.2 |
| **Чётность** | **Even** (по чётности) | ⚠️ КРИТИЧЕСКИ ВАЖНО! Без этого весы не отвечают |
| **Стоп-биты** | **1** | Стандарт |
| **Биты данных** | **8** | Стандарт |

> ⚠️ **ВАЖНО:** Не используйте Протокол №1 (ASCII) или "1С" — они работают нестабильно.  
> Протокол №2 — официальный и самый надёжный для всех моделей Масса-К.

#### Сохранение настроек

1. Нажмите **ENTER** или **SET** для сохранения
2. Выйдите из меню (обычно кнопка **ВЫХОД** или удержание **МЕНЮ** 3 сек)
3. Перезагрузите весы (выключите и включите)

## 2. Протокол обмена данными

### Протокол №2 (бинарный, запрос-ответ)

Масса-К работает по принципу **Master-Slave**: компьютер отправляет команду (1 байт), весы отвечают фиксированным пакетом.

### Основные команды

| Команда (HEX) | Название | Ответ | Описание |
|:-------------:|----------|:-----:|----------|
| **0x45** | Запрос массы | 2 байта | Текущий вес, отображаемый на индикаторе |
| **0x44** | Запрос статуса | 2 байта | Состояние весов (стабильность, индикаторы) |
| **0x48** | Запрос дискретности | 2 байта | Цена деления (1г, 0.1г, 10г и т.д.) |
| **0x4A** | Полный запрос | 5 байт | Масса + статус + дискретность |
| **0x0D** | Выборка тары | Нет ответа | Обнуление тары |
| **0x0E** | Установка нуля | Нет ответа | Обнуление веса |

### Команда 0x45: Запрос массы (основная)

**Запрос:** 1 байт `0x45`

**Ответ:** 2 байта (16 бит), Little Endian

```
Байт 0: D0-D7 (младшие 8 бит)
Байт 1: D8-D15 (старшие 8 бит)
```

**Расшифровка битов:**
- **D15** (старший бит байта 1) — знак массы: `0` = "+", `1` = "-"
- **D14-D0** (остальные 15 бит) — масса в граммах

**Пример парсинга:**
```python
raw_val = data[0] | (data[1] << 8)  # Little Endian
is_negative = (raw_val & 0x8000) != 0  # D15 — знак
mass_grams = raw_val & 0x7FFF  # D14-D0 — масса
mass_kg = mass_grams / 1000.0
if is_negative:
    mass_kg = -mass_kg
```

**Реальный пример:**
```
Запрос:  45
Ответ:   4A 01
Разбор:  raw_val = 0x014A = 330
         mass_grams = 330 & 0x7FFF = 330
         mass_kg = 330 / 1000 = 0.330 кг
```

### Команда 0x44: Запрос статуса

**Ответ:** 2 байта

| Бит | Описание |
|-----|----------|
| D7 | Взвешивание завершено: `0` = нет, `1` = да |
| D6 | Индикатор "Нестабильно": `0` = нет, `1` = да |
| D5 | Индикатор "Тара": `0` = нет, `1` = да |
| D15-D8, D4-D0 | Не определено |

### Команда 0x4A: Полный запрос (5 байт)

**Ответ:** 5 байт

| Байт | Описание |
|------|----------|
| 0 | Статус (D7=завершено, D6=нестабильно, D5=тара) |
| 1 | Дискретность: `0`=1г, `1`=0.1г, `4`=10г, `5`=100г, `6`=100г (для 3/6т) |
| 2-4 | Масса (D39=знак, D38-D16=граммы) |

### Команды управления (без ответа)

- **0x0D** — Выборка массы тары (обнуление тары)
- **0x0E** — Установка нуля (обнуление веса)

После отправки этих команд весы не возвращают ответ.

## 3. Использование с библиотекой ScalesComponent

### Пример на Python

```python
import win32com.client
import pythoncom

pythoncom.CoInitialize()
scales = win32com.client.Dispatch("ScalesComponent.Scales.1")

# Подключение (обратите внимание: 4800 бод, тип MassaK)
if scales.Connect("COM1", 4800, "MassaK"):
    print("✅ Весы подключены")
    
    # Получение стабильного веса (ждёт до 5 сек)
    weight = scales.GetStableWeight(5000)
    
    if weight > 0:
        print(f"✅ Стабильный вес: {weight} кг")
    else:
        print(f"❌ Ошибка: {scales.GetLastError()}")
    
    # Тарирование
    scales.Tare()
    print("✅ Тарирование выполнено")
    
    # Отключение
    scales.Disconnect()
else:
    print(f"❌ Ошибка подключения: {scales.GetLastError()}")

pythoncom.CoUninitialize()
```

## 4. Типичные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| **Весы не отвечают** | Неправильная скорость | Установите **4800 бод** в меню весов |
| **Весы не отвечают** | Неправильная чётность | Установите **Parity: Even** в коде |
| **Весы не отвечают** | Нуль-модемный кабель | Используйте **обычный прямой кабель** (2→2, 3→3, 5→5) |
| **Первый запрос проходит, дальше тишина** | Буфер не очищается | Библиотека автоматически делает `DiscardInBuffer()` перед каждым запросом |
| **Вес всегда 0** | Нестабильные показания | Используйте `GetStableWeight()` вместо `GetCurrentWeight()` |
| **COM-порт не открывается** | Порт занят другой программой | Закройте 1С, терминал, другую программу |
| **Ошибка 0x800401F3** | DLL не зарегистрирована | Запустите `regasm` от администратора |
| **Скачущие показания** | Вибрация / сквозняк | Поставьте весы на устойчивую поверхность |

## 5. Диагностика

### Как проверить, что весы отвечают

#### Через Python (тестовый скрипт)

```python
import serial
import time

ser = serial.Serial(
    port='COM1',
    baudrate=4800,
    parity=serial.PARITY_EVEN,
    bytesize=serial.EIGHTBITS,
    stopbits=serial.STOPBITS_ONE,
    timeout=1
)

# Отправляем запрос массы
ser.reset_input_buffer()
ser.write(b'\x45')
time.sleep(0.1)

# Читаем ответ
response = ser.read(2)
if len(response) == 2:
    raw_val = response[0] | (response[1] << 8)
    mass_grams = raw_val & 0x7FFF
    mass_kg = mass_grams / 1000.0
    print(f"Вес: {mass_kg} кг")
else:
    print("Нет ответа от весов")

ser.close()
```

#### Через Диспетчер устройств Windows

1. Открой **Диспетчер устройств** → **Порты (COM и LPT)**
2. Убедись, что COM-порт отображается без восклицательных знаков
3. Если есть жёлтый треугольник — переустанови драйвер USB-COM адаптера

#### Через терминал (Putty)

⚠️ **Внимание:** Putty не подходит для бинарного протокола, так как показывает только ASCII-символы. Используйте Python-скрипт выше.

## 6. Отличия от других весов

| Параметр | Масса-К | CAS | Mettler Toledo |
|----------|---------|-----|----------------|
| **Протокол** | Бинарный (запрос-ответ) | ASCII (непрерывный) | ASCII (непрерывный) |
| **Скорость** | 4800 бод | 9600 бод | 9600 бод |
| **Чётность** | **Even** | None | None |
| **Кабель** | Прямой (2→2, 3→3) | Нуль-модемный (2→3, 3→2) | Нуль-модемный |
| **Команда** | 0x45 (запрос) | Нет (непрерывно) | Нет (непрерывно) |
| **Ответ** | 2 байта | Строка ASCII | Строка ASCII |

## 7. Поддерживаемые модели

Протокол №2 универсален и работает со всеми современными терминалами Масса-К:

- ✅ **ТВ-А** (терминал весовой)
- ✅ **Т-А** (терминал)
- ✅ **МК-А** (модуль взвешивающий)
- ✅ **МА** (серия МА)
- ✅ **ВИ** (весовой индикатор)

Если у вас старая модель с прошивкой до 2010 года, возможно, потребуется использовать Протокол №1 (ASCII). В этом случае создайте Issue в репозитории.
