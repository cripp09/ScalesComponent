# 📚 Документация по терминалам весов

В этой папке собрана практическая документация по подключению конкретных моделей весовых терминалов.

## Зачем это нужно?

Производители часто кладут бумажные инструкции на китайском/корейском, а в интернете — только общие описания. Здесь мы собираем **реальный опыт подключения**: как включить режим передачи, какой кабель нужен, как подключить тензодатчик.

## Список терминалов

| Производитель | Модель | Статус |
|---------------|--------|--------|
| CAS | [CI-200A](CAS/CI-200A.md) | ✅ Проверено |
| CAS | CI-5200 | 📝 Планируется |
| Massa-K | MK-15.3 | 📝 Планируется |
| Mettler Toledo | IND236 | 📝 Планируется |

## Как добавить свой терминал

1. Скопируй шаблон из [`_templates/terminal-template.md`](_templates/terminal-template.md)
2. Заполни по своей модели
3. Создай Pull Request

## Структура записи

Каждая страница содержит:
1. **Включение режима передачи** — пошаговая инструкция по меню терминала
2. **Распиновка COM-порта** — какой пин куда подключать
3. **Подключение тензодатчика** — цвета проводов, напряжения
4. **Протокол обмена** — реальный формат данных с примерами
5. **Типичные проблемы** — FAQ по подключению

---

*Документация ведётся сообществом. Если у тебя есть опыт подключения терминала, которого нет в списке — добавь его!*
