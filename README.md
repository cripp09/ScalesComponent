## 🚀 Возможности

✅ **3 бренда с гарантией работы** (CAS, Massa-K, Metrisoft) — физически протестированы на реальном оборудовании  
✅ **12 брендов по документации** — реализованы по официальным протоколам производителей  
✅ Автоматическое определение типа весов по протоколу (режим `Auto`)  
✅ Асинхронное чтение данных в фоновом потоке без блокировки интерфейса  
✅ Определение стабильности веса по аппаратным флагам производителя  
✅ Кроссплатформенность: работает из 1С, Python, C#, PowerShell, Delphi, Node.js

## 💻 Системные требования

- ОС: Windows 7/8/10/11
- .NET Framework 4.7.2 или выше
- COM-порт (физический или виртуальный USB-to-Serial)

## ⚡ Быстрый старт

### 1. Регистрация DLL
Запустите `cmd` **от имени администратора** и выполните:
```cmd
C:\Windows\Microsoft.NET\Framework\v4.0.30319\regasm.exe "путь\к\ScalesComponent.dll" /codebase
```
*(Для 64-битной 1С используйте путь `Framework64`)*

### 2. Использование в 1С:Предприятие
```bsl
Весы = Новый COMОбъект("ScalesComponent.Scales.1");
Если Весы.Connect("COM3", 9600, "Auto") Тогда
    Вес = Весы.GetStableWeight(5000); // Ждем стабильный вес до 5 сек
    Сообщить("Вес: " + Вес + " кг");
    Весы.Disconnect();
КонецЕсли;
```

### 3. Использование в Python
```bash
pip install pywin32
```
```python
import win32com.client
scales = win32com.client.Dispatch("ScalesComponent.Scales.1")
scales.Connect("COM3", 9600, "Auto")
print(f"Вес: {scales.GetStableWeight(5000)} кг")
scales.Disconnect()
```

## 🔌 Краткий API
| Метод | Описание |
| :--- | :--- |
| `Connect(port, baud, type)` | Подключиться к весам |
| `Disconnect()` | Отключиться и освободить порт |
| `GetCurrentWeight()` | Мгновенно получить последний вес из кэша |
| `GetStableWeight(timeout)` | Блокировать поток и ждать стабильный вес (мс) |
| `IsConnected()` / `IsStable()` | Проверка статуса соединения и стабильности |
| `Tare()` | Отправить команду тарирования |
| `GetLastError()` | Получить текст последней ошибки |

## 🤝 Как внести свой вклад

Этот проект создан с открытым исходным кодом, и мы приветствуем любую помощь сообщества! Если у вас есть опыт подключения весов, которых нет в списке, или вы нашли способ улучшить код — мы будем рады вашему участию.

**Чем вы можете помочь:**
1. **Добавить поддержку новых весов:** Напишите новый класс-парсер, реализующий интерфейс `IScalesParser`, и добавьте его в `AutoDetectParser`.
2. **Пополнить базу знаний:** Добавьте инструкцию по подключению вашего терминала (распиновка COM-порта, настройки сервисного меню, реальные логи данных) в папку `Docs/`, используя [этот шаблон](Docs/_templates/terminal-template.md). *Такая документация бесценна для других разработчиков!*
3. **Исправить ошибки или улучшить код:** Нашли баг или есть идея по оптимизации чтения порта? Мы открыты для обсуждений.
4. **Сообщить о проблеме:** Создайте [Issue](https://github.com/cripp09/ScalesComponent/issues), если столкнулись с трудностями или у вас есть предложение по новой функции (например, поддержка TCP/IP).

**Как начать:**
1. Сделайте **Fork** этого репозитория.
2. Создайте новую ветку для своих изменений (`git checkout -b feature/new-scale-brand`).
3. Внесите изменения и закоммитьте их (`git commit -m 'Добавлена поддержка весов Brand X и документация'`).
4. Отправьте **Pull Request** в основной репозиторий.

Любой вклад, даже небольшая правка в документации или добавление одного нового типа весов, делает этот проект лучше для всех! 🚀
